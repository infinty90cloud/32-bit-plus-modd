This mod allows you to push the game to it's limits by going past the 32 bit limit by making the int limit 4,294,967,296. This is useful if you want to break Todd's game even more by using the fortify restoration loop to Get up to 4 BILLION% on any stat.

   How to use
___________________________________________________
Step 1. Enter dragons reach (the palace in whiterun) 
Step 2. Open the dresser Right next to the kitchen.
Step 3. type the following command: player.addperk 1300d62 this will make you deal 4,294,967,296 damage per hit.
Step 4 if you want your damage to be set to 0 you can type: player.setav attackdamagemult 0
Step 5. Done ( you should see a message telling you that the integer effect is in place.)

Features:
_______________________________________________________________________


Max stat value is 2x better.
You do INSANE amounts of damage.
Game = 100% jankier.

Known "bugs":
__________________________________________________________________

1.Numbers in the UI that are over 2 billion are still displayed as negative numbers but aren't actually negative numbers.
2.Sometimes you might have to open the dresser again if the mod stops working.
3. opening the book shelf next to the dresser will crash the game this is a fail-safe so if the game is too broken you can emergency crash the game.

Installation:
___________________________________________________________________

Activate ALL of the .esp files in the mod there are 6 of them.
Only download the updated version
You do not need skse or any script exteneder just copy the files in the data folder in the zip file to Skyrim Special Edition /Data or Skyrim/Data
